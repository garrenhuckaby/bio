## The idea
Build a budgeting tool that supports category transfers, monthly rollovers, and transaction categorization.

## System
Google Sheets stores the budget and transaction data. Apps Script provides the application interface and update logic.

## Lessons to document
The case study will explain how category balances, transfers, and month boundaries work. Financial records and credentials are excluded from this site.
